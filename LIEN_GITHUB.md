# Lien GitHub — Projet 4

## API de Gestion d'un Blog (Articles & Commentaires)

**Dépôt GitHub (public) :**

https://github.com/jacquessiyou4/spring-boot-projet-4-blog-api

---

### Description
Publication d'articles, lecture paginée ou unitaire, mise à jour, suppression, dépôt et modération de commentaires.

### Auteur
SIYOU NOUKIMI JACQUES

### Stack technique
Spring Boot 3.3 · Java 17 · Spring Data JPA · PostgreSQL 15 · Docker Compose · Swagger (springdoc-openapi)

### Documentation de l'API
Une fois l'application démarrée, la documentation Swagger UI est accessible sur :

    http://localhost:8080/api/swagger-ui.html

### Démarrage rapide
```bash
git clone https://github.com/jacquessiyou4/spring-boot-projet-4-blog-api.git
cd spring-boot-projet-4-blog-api
docker compose up -d --build
```

Les instructions détaillées d'installation et de test figurent dans le fichier `README.md` du dépôt.
